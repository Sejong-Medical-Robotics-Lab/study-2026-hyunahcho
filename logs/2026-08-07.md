## Go2 실기체 조작 및 Waypoint 주행 실습

## 오늘 배운 것

1. Go2 실기체를 사람이 직접 조작하는 방법과 Python 코드로 자동으로 움직이는 방법의 차이를 배웠다.
    
    Teleop / 조이스틱 조작은 ****사람이 키보드나 조이스틱을 이용해 실시간으로 이동 방향을 결정하는 수동 조작 방식이다.
    
    Python 코드 + Sport Client API 방식은 Python 코드에 이동 순서를 미리 작성하고, 코드가 Sport Client API의 이동 함수를 호출하여 Go2를 움직이는 방식이다.
    
2. Python 코드와 Sport Client API의 관계를 이해했다. Python 코드 자체가 Go2를 직접 움직이는 것이 아니라, Python 코드에서 Sport Client API 함수를 사용해 이동 명령을 전달한다.
3. Go2의 high-level 제어에서는 사용자가 각 다리 관절을 직접 제어하지 않고, 전진 속도와 회전 속도와 같은 이동 의도만 명령한다는 것을 배웠다. 실제 12개 관절의 보행 동작은 Go2 내부의 보행 제어기가 처리한다.
4. 속도와 시간을 이용하여 로봇의 이동거리를 대략적으로 결정할 수 있고, 회전 역시 각속도와 시간을 이용하여 원하는 회전량을 설계할 수 있다. 직진과 회전을 순서대로 조합하면 여러 개의 waypoint를 따라 이동하는 경로를 만들 수 있다.
5. 오늘 실습에서는 미리 계산한 이동 시퀀스를 이용하여 waypoint를 따라갔다.

5. Python 코드에 미리 작성된 이동 시퀀스를 실행하여 Go2를 움직였다.

## 막힌 것 / 이해가 더 필요했던 것

1. 처음에는 Python 코드, Sport Client API, Teleop의 관계가 헷갈렸는데, 이동 시퀀스 파이썬 코드가 sport client api를 호출하고, Go2를 이동시키는 것으로 이해하였다.
2. 이번 waypoint 주행은 속도와 시간을 미리 설정하는 시간 기반 제어였으며, 계산한 이동거리와 실제 이동거리 사이에 오차가 발생할 수 있다.
3. 원하는 위치에 더 정확하게 도달하려면 단순히 정해진 시간 동안 이동하는 것뿐만 아니라, odom 등의 상태 데이터를 이용하여 실제 위치와 방향을 확인하면서 제어하는 방법도 알아보고 싶다.
4. 키보드 조작 실습 때 키를 끊어서 클릭하였는데, Go2의 움직임이 부자연스러웠다. 키를 보다 연속적으로 자연스럽게 클릭하는 것이 더욱 자연스러운 보행에 도움이 됨을 알게 되었다.

## 한 줄 소감

Go2를 직접 조이스틱으로 조작하기도 하고, Python 코드가 Sport Client API를 호출하여 실제 로봇을 정해진 거리와 방향으로 움직이는 waypoint 주행까지 수행했다. Go2를 직접 조종해보니 신기했고, 수동 조작과 코드 기반 로봇 제어의 차이를 이해할 수 있었다. Go2가 알아서 균형을 잡는 모습도 확인할 수 있었다.
