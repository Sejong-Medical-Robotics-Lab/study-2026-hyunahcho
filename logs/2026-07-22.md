# 학습일지 — 2026-07-22 (Week 1, 공통교육 1일차)

## 오늘 배운 것

1. 로봇 플랫폼을 직접 다루기 전에 꼭 알아야 하는 위험 요소와 안전수칙을 배웠다.
2. Ubuntu의 터미널을 열고 기본적인 터미널 명령어를 사용해 보았다.
3. Git과 GitHub가 무엇인지 배우고, 개인 학습용 repository를 생성하였다.
4. Ubuntu 환경에 ROS2 Humble을 설치하고 기본 환경 설정을 진행하였다.
5. talker와 listener를 실행하여 ROS2에서 노드끼리 메시지를 주고받는 통신을 확인하였다.
6. turtlesim을 실행하고 키보드 방향키로 거북이를 직접 움직여 보았다.

## 직접 해본 것 / 성공한 것

1. Ubuntu에서 터미널을 열고 명령어를 입력하여 폴더를 만들고 이동해 보았다.
2. GitHub에 개인 학습 저장소를 만들고 Ubuntu 터미널과 연결하였다.
3. ROS2 Humble 설치를 완료하였다.
4. 두 개의 터미널에서 talker와 listener를 각각 실행하여 같은 메시지가 송수신되는 것을 확인하였다.
5. turtlesim 창을 실행하고 거북이를 직접 키보드로 움직이는 데 성공하였다.

## 막힌 것 / 이해가 더 필요했던 것

1. GitHub를 처음 사용하다 보니 commit과 push가 각각 무엇인지 헷갈렸다.
2. GitHub 계정의 비밀번호가 아니라 개인 액세스 토큰을 사용해 인증한다는 점이 낯설었다.
3. ROS2의 통신 과정에 대해서는 아직 충분히 이해하지 못했다.

## 한 줄 소감

지금까지 Linux와 GitHub를 제대로 사용해 본 경험이 거의 없어 실습을 따라가고 이해하는 데 시간이 조금 걸렸다. 앞으로 터미널과 GitHub를 자주 사용하면서 점차 익숙해질 것 같다.
