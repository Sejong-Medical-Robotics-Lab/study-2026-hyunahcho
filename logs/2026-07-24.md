# 학습일지 — 2026-07-24 (Week 1, 공통교육 2일차)

## 오늘 배운 것

1. ROS2의 핵심 구성 요소인 노드, 토픽, 서비스, 메시지의 개념과 각각의 차이를 배웠다.
2. ROS2 시스템의 통신 구조와 데이터를 확인하는 방법을 배웠다.
3. Python 기반 노드를 작성해보았다.
4. RViz2가 좌표계를 시각화할 때 사용된다는 것을 배웠다.

## 직접 해본 것 / 성공한 것

1. turtlesim을 실행하고 키보드 조종 노드를 이용해 거북이를 움직여보았다.
2. 서비스를 호출하여 두 번째 거북이를 생성하였고, 거북이의 펜 색상과 굵기를 변경했다.
3. 리매핑을 사용하여 두 번째 거북이를 조종하였다.
4. `my_first_pkg` 패키지를 만들고 `greeter.py` 발행 노드와 `replier.py` 구독 노드를 직접 작성하였다.
5. `greeter`가 메시지를 발행하고, `replier`가 메시지를 구독하는 방식을 확인하였다.
6. tf2 거북이 추격 데모를 실행하였다.
7. RViz2에서 Fixed Frame을 설정하고 TF 항목을 추가하여 거북이 좌표계를 시각화하였다.

## 막힌 것 / 이해가 더 필요한 것

1. Terminator에서 방향키 입력은 현재 활성화된 터미널로 전달되므로,  turtlesim 거북이를 움직이기 위해서는 실행된 터미널을 선택해야 한다는 점을 처음에는 놓쳤다.
2. rqt_graph의 필터 설정이나 표시 방식을 잘못 설정하면 실행 중인 노드와 토픽이 있어도 그래프가 보이지 않을 수 있다는 점이 헷갈렸다.
3. Rviz2의 구체적 작동 방식에 대해 더 잘 이해해야 할 것 같다.
