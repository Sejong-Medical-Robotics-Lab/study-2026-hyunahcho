## G1 Humanoid 실기체 실습

### 오늘 배운 것

1. G1을 직접 조종해보았으며 L2+B와 같은 명령들을 익혔다.
2. G1 실기체 제어를 위해 Unitree SDK2 Python을 설치하고, Python에서 `unitree_sdk2py`를 이용하여 실기체와 통신할 수 있다.
3. 실기체용 코드인 `g1-real`은 Unitree SDK 위에서 동작하며, 주요 파일은 다음과 같다는 것을 확인하였다. (`g1_real_monitor.py` ,`g1_real_sequence.py` )
4. `g1_real_monitor.py precheck`를 통해 G1의 상태 스트림, IMU 기울기, 모터 온도, 관절 토크 등을 확인할 수 있다.
5. 공유기 네트워크를 통해 여러명이 동시에 G1에 연결할 수 있으며, 내 노트북에서는 `wlo1` 인터페이스를 이용하여 G1과 통신할 수 있었다.
6. `-list-actions`를 이용해 실제 G1에서 지원하는 상체 액션 목록을 확인하였다.
7. G1의 상체 액션에는 `right kiss`, `hug`, `heart`, `hands up`, `clap`, `high wave`, `right hand up` 등 다양한 동작이 있었다.
8. 실기체에서 상체 동작만 명령하더라도 팔 움직임에 의해 무게중심이 변하기 때문에 하체와 허리 관절이 균형 유지를 위해 미세하게 보상할 수 있다.

### 막힌 것 / 이해가 더 필요했던 것

1. 처음 Unitree SDK 설치 후 SDK 폴더 안에서는 import가 되었지만 다른 폴더에서 `No module named 'unitree_sdk2py'` 오류가 발생하였다. 가상환경을 생성한 뒤 SDK를 다시 설치하여 해결하였다.
2. 첫 번째 상체 시퀀스에서 `right kiss → hug`까지는 성공했지만 `heart` 실행 시 ExecuteAction(heart=20)  오류가 발생하였다.
3. `hug`, `heart`와 같은 일부 동작 뒤에 `release arm`을 실행하여 action 거부 없이 실행되도록 하였다.
4. 앞으로는 각 상체 동작별로 `release arm`이 필요한지, 어떤 동작은 연속 실행이 가능한지, 그리고 실제 G1의 FSM 상태와 Action 실행 가능 조건의 관계를 더 확인해보고 싶다.

### 한 줄 소감

시뮬레이터에서는 명령 순서와 대기 시간만 고려하면 되는 경우가 많았지만, 실제 G1에서는 네트워크, 안전 절차, 동작 해제 조건까지 함께 고려해야 시퀀스가 정상적으로 동작한다는 점이 가장 인상적이었다. 

나만의 시퀀스대로 G1이 동작하는 점이 흥미로웠고, LOW level 제어를 통해 새로운 Action을 만들어 보고 싶다.
